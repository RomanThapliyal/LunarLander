## 🌙 Welcome!

Welcome to **Lunar Lander**!

Take control of your lunar lander and try to make safe
landings while managing your fuel and navigating the terrain.

This project was built with **Unity and C#** as part of my
game development journey.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🌍 Multiple Levels | Different levels with unique terrain |
| ⛽ Fuel Management | Carefully manage your limited fuel |
| 🚀 Landing Mechanics | Control your speed and angle for safe landings |
| 🏆 Scoring | Earn scores based on your performance |
| 🗺️ Minimap | Keep track of your surroundings |
| 📖 Guide Screen | Learn how to play |
| ⚙️ Custom Systems | Gameplay systems built specifically for the project |

## 📥 Download

### Latest Version — `v1.0.0`

Download the playable Windows build from the
**[latest release](../../releases/latest)**.

1. Download `LunarLander-v1.0.0.zip`
2. Extract the ZIP
3. Open the extracted folder
4. Run the `.exe`
5. 🚀 Start landing!

## 🎮 Controls

| Key | Action |
|---|---|
| W / ↑ | Thrust |
| A / ← | Rotate Left |
| D / → | Rotate Right |
| K | Toggle Minimap |
